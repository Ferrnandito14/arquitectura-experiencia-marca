1. ¿QUÉ ES UNA OPORTUNIDAD?
============================================================

Una oportunidad es cualquier posibilidad concreta que puede
resolver una necesidad, generar una conexión o permitir que
un usuario avance dentro de su trayectoria deportiva o
profesional.

Una oportunidad puede ser:

- una organización;
- una persona;
- un servicio;
- una vacante;
- un tryout;
- una competición;
- un entrenamiento;
- una academia;
- un evento;
- una oportunidad de scouting;
- una oportunidad laboral;
- una posibilidad de colaboración.

IMPORTANTE:

NO todas las oportunidades son iguales.

Cada tipo tendrá:

- atributos;
- requisitos;
- disponibilidad;
- condiciones;
- estado;
- audiencia;
- criterios de compatibilidad.

============================================================
29. OPORTUNIDAD ACTIVA
============================================================

Una oportunidad activa significa:

- existe;
- está disponible;
- cumple las condiciones para ser mostrada;
- puede recibir acciones.

Una oportunidad cerrada NO debe continuar apareciendo
como recomendación activa.


============================================================
30. VERIFICACIÓN
============================================================

La plataforma debe distinguir entre:

NO VERIFICADA
VERIFICADA
VERIFICADA PARCIALMENTE

Esto puede aplicarse a:

- clubes;
- academias;
- profesionales;
- eventos;
- oportunidades.

No definir todavía el sistema definitivo de verificación.

31. FUENTE DE LA OPORTUNIDAD
============================================================

Una oportunidad puede provenir de:

1. Usuario.
2. Organización.
3. Profesional.
4. Administrador.
5. Integración externa.

La fuente deberá conservarse.

Esto será importante posteriormente para confianza,
actualización y trazabilidad.

45. PRINCIPIO DE INFORMACIÓN MÍNIMA ÚTIL
============================================================

Una oportunidad no debe mostrar 50 datos de entrada.

Debe mostrar primero lo que permite decidir:

¿ME INTERESA?

Ejemplo academia:

- nombre;
- distancia;
- edad;
- nivel;
- precio;
- horarios;
- competición.

Después:

VER MÁS.

============================================================
52. REGLA FUNDAMENTAL
============================================================

Una oportunidad debe existir porque:

1. Resuelve una necesidad.
2. Permite una acción.
3. Puede ser evaluada por criterios.
4. Puede entrar en un proceso de matching.
5. Tiene suficiente información para determinar su relevancia.

- sistema de reputación;
- monetización;
